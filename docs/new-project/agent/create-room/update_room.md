ภาพแสดง 3 ช่วงการใช้งาน:
1. ก่อนค้นหา — แสดงโครงการและแผนที่ พร้อมปุ่ม “ค้นหาสถานที่ใกล้เคียงทั้งหมด”
2. เลือกสถานที่ — หมวดพับได้ แสดง การเดินทาง 2/5 = เลือกแล้ว 2 จากที่พบ 5 พร้อมระยะทางทุกรายการ
3. ดูหมุดรวม — ขยายแผนที่ให้เห็นสถานที่ที่เลือกจากทุกหมวด แตะหมุดดูชื่อและระยะทางได้
รายละเอียดการใช้งานที่ควรยึดตามแบบ:
- เลือกทั้งหมดรายหมวด กดซ้ำเพื่อยกเลิกทั้งหมวด; เลือกบางรายการแสดงเครื่องหมายขีด “−”
- สีหมุดตรงกับไอคอนหมวด ส่วนโครงการใช้หมุดอาคารสีเหลือง
- แผนที่ภาพรวมแสดง หมุดที่เลือกไว้ทั้งหมด แม้พับหรือเปลี่ยนหมวด
- ระยะทางเรียงใกล้ไปไกล และระบุว่าเป็น ระยะทางเส้นตรง
- จำนวนรวมอยู่เหนือปุ่ม “เสร็จแล้ว” อัปเดตทันที
- หมวดที่ไม่พบสถานที่แสดง “ไม่พบสถานที่” ส่วนค้นหาล้มเหลวแสดง “ลองใหม่” ให้แยกกันชัดเจน
ตอนทำจริงควรเพิ่มความสูงแถวรายการจากภาพให้กดง่าย และใช้สถานะ “เลือกบางส่วน” ที่หัวหมวดครับ ภาพนี้เป็นตัวอย่างจาก imagegen ระยะทางสมมติ ยังไม่ได้แก้โค้ด
