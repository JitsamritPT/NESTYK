# Add Lead: สองส่วนของฟอร์ม

## 1. เก็บ Lead ไว้ก่อน

บันทึกได้ทันทีเมื่อกรอก **ชื่อ** และ **เบอร์ติดต่อ** ทั้งสองช่องเป็น required สำหรับการบันทึก Lead

สัญชาติ อาชีพ และประเภทวีซ่าแสดงในส่วนผู้ติดต่อทั้งหมด (ไม่ซ่อนในเมนูขยาย) ไม่ใช้กรองหรือคิดคะแนนห้อง

## 2. ข้อมูลสำหรับจับคู่ห้อง

ส่วนนี้ไม่บังคับก่อนบันทึก Lead แต่การแสดง **คะแนน match เป็น %** ในอนาคตต้องมีอย่างน้อย:

1. **งบสูงสุดต่อเดือน** ที่เป็นตัวเลขบวก
2. **จังหวัด** จากตัวเลือกพื้นที่ หรือจากหมุดแผนที่

เลือกหลายเขต/อำเภอได้; หมุดและรัศมีเป็นทางเลือกสำหรับทำเลเฉพาะ เมื่อแก้จังหวัด/พื้นที่ด้วยตัวเลือก ระบบล้างหมุดเดิมเพื่อไม่ให้เงื่อนไขทำเลขัดกัน

ประเภทห้องและระยะเวลาเช่าอยู่ในส่วนหลัก แต่ยังไม่บังคับ เพราะลูกค้าอาจยืดหยุ่นได้ ระยะเวลาเช่าที่ระบุควรใช้เลือกราคาของสัญญาระยะนั้นก่อนเทียบกับงบ

งบต่ำสุด แพลนย้ายเข้า รายละเอียดทำเล และหมุดแผนที่แสดงในส่วนจับคู่ห้อง (ไม่ซ่อนในเมนูขยาย)

สัตว์เลี้ยง รถ การสูบบุหรี่ และจำนวนผู้อยู่เป็น **โน้ตดูแลลูกค้า** สำหรับ agent อ่าน ไม่ใช้กรองหรือคิดคะแนนห้อง

การกรอกครบสองช่องหลักแสดงสถานะ **“ข้อมูลหลักพร้อมสำหรับจับคู่ห้อง”** เท่านั้น ขณะนี้ยังไม่มี API คำนวณ matching หรือคะแนนจริง การบันทึก Lead ยังไม่เปลี่ยนสถานะ Lead ตามความครบของฟอร์ม
